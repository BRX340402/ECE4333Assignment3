# Test 5：定位显示、对比地面标定、120°/360°恢复搜索

基于最后合并版本 Test4（Test3 + 队友可选 PD + 主页面日志/急停）修改。UNO UV=35。
请同时上传 UNO_Assignment2 和 ESP32_Assignment2 两个完整文件夹。ESP32 开发板包沿用项目的 1.0.4、ESP32 Dev Module、PSRAM Enabled、Huge APP；不因这次更新更换驱动。

## 先做什么
1. 上传后开关切回 Cam。ESP32 仍先高分辨率初始化，然后默认 CIF。网页和压缩网页已同步。
2. 主页面确认 UNO 版本匹配，停止车。展开 Line and search settings。
3. 将三个地面传感器全部置于白色底面（保持正常离地高度），点击 Sample white floor；然后全部置于足够宽的黑色材料，点击 Sample black line。
4. 点击 Apply measured threshold。每个样本采集 6 次新遥测；黑白读数区间间隔须至少 60，否则拒绝自动标定。既支持黑色高读数，也支持黑色低读数。单一阈值不能分离三个传感器时，需要调高度/光照/传感器，不能盲目降低阈值。
5. 检查 RA=120、SA=360；旧角度首次升级自动迁移，后续保存的设置不会每次启动被覆盖。已有黑白阈值保留，需按上面步骤重新标定。
6. 可沿用你实测的 cruise=60、reduced=30、red pixels=170；测试红灯停车请勾选 Stop on red。绿色、两帧累计 STOP、STOP 停 3 秒及通过防重复计数保留。
7. 在交通灯起点放车，车头初始方向作为 +X，左侧 +Y，每次 Start 将位置、航向及陀螺仪相对角清零。通电初始化时保持静止以估计陀螺仪零偏。

## 已确认的代码问题与修改
- 原 black(v) 只接受 600–850。是否因此漏线取决于实测读数；例如黑色读数 980 会被旧阈值排除。现在允许完整 0–1023 ADC 范围，并通过黑白实测决定区间和极性。
- 原搜索使用“时间到 OR 角度到”换阶段，陀螺仪正常时也可能未转足角度。现在正常陀螺仪以累计角度为准；名义时间只在无陀螺仪时使用。角度卡住仍有独立超时，方向错误报告 FAULT10 而非隐蔽地转为定时。
- 原任一地面传感器连续三个程序循环命中就退出搜索，不代表稳定居中。现在要求窄中心线或双侧黑/中心白的对称边界持续至少60ms；健康陀螺仪下排除与失线方向相差150°以上的反向线路。
- 三个传感器全黑时无法区别交叉口与宽黑块。现在最多600ms减速保持进入方向，随后进入搜索，防止长期盲直行。双侧黑、中心白仍按对称边界直行。
- 右转120°，从该位置反向左转360°；若仍找不到，再右转240°返回起始方向。超声确认前方至少22cm才允许100ms小幅前进。最多5次、总共120秒；故障仍可停止。找到有效线路会提前结束搜索，不会强制完成整圈。
- 临时 I2C 读取失败后，只要启动零偏标定成功，后续允许重新读取陀螺仪；不再因单次失败永久放弃。

## 定位：真实实现和准确性边界
UNO 本来已有轮速指令模型与陀螺仪融合，本次保留两套独立轨迹并修正每次启动的共同原点。主页面显示蓝色模型预测、绿色陀螺仪辅助估计，可输入实测路线点形成白色参考线。掉 Wi-Fi 后 UNO 本地控制、估计和搜线仍继续；浏览器不能记录断线期间未收到的数据。

陀螺仪测转动，不能单独测出X/Y。这里没有轮编码器反馈，位移来自 PWM→速度标定，必须修改 UNO_Assignment2/PoseConfig.h 的 LEFT_CM_S_PER_PWM、RIGHT_CM_S_PER_PWM、TRACK_WIDTH_CM。当前0.07只是原项目试验值，不是实测结果。直线标定初值可以用实测距离/(运行秒数×PWM)，再用不同速度/转弯数据验证。左右速度系数仅用于估计，不对右轮输出加补偿。

图中没有全部中心线顶点、起点与标志相对坐标，因此未捏造地图坐标或自动吸附到某条支路。当前方向记忆改善局部恢复；不是已完成的全局航点导航。主页面参考点只作比较，不能改变车辆动作。8字交点需按路线顺序出现两次，不能仅凭最近点认定所在支路。

在 WAIT FOR GREEN 或 STOP HOLD 时，可以输入已测的小车 X/Y/heading，点击 Correct estimate at measured landmark。此命令N209只修正融合估计，不改变原运动学预测、不启动电机、不重置控制用原始陀螺仪角；网页提示为已发送，必须看遥测确认。填写的是小车位置，不是STOP牌位置。STOP_HOLD会正常结束，所以操作不及时会被UNO拒绝。

原自动相机地标修正仍需要实测 LANDMARK_X/Y、APPROACH_HEADING、CAMERA_FORWARD、相机内参以及距离标定；默认未开启。主页面手工校正不等于相机自动融合。只支持原代码的单一指定接近方向；8字两次不同方向接近不能共用未经区分的地标。

## 对照作业评分要求
- 循迹/搜索、状态机、交通识别、交点直行、急停、串口协议：代码实现，仍需跑实物路线评估。
- 运动学位置/航向预测与陀螺仪辅助估计：有实现与显示；精度需实测标定。
- 记录/比较：主页面 Start recording / Stop recording / Download CSV；可输入参考轨迹，实际坐标须另外测量，不能拿估计当真值。
- 相机自动融合：原代码保留但默认关闭，实测配置与验证尚未完成。
- 视觉目标跟随内外环：本版未完整实现；可选PD循迹与交点稳向不能冒充视觉目标跟随，不能宣称所有评分点已满足。
- 比赛红灯必须停车：应勾选 Stop on red，未勾选仍按你保留的减速逻辑运行。
