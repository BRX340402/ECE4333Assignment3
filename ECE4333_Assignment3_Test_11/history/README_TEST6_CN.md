# Test6：陀螺仪导航默认关闭，增加手动归零
本文件优先于包内 Test5 历史说明。UNO UV=36，必须同时上传本包 UNO 和 ESP32。

## 启动
1. 上传后切 Cam。启动保持静止约1秒。默认相机SVGA（恢复此前可用配置），热点名称密码不变。
2. 在主页面 Car control 选项卡找到 Optional gyro navigation。默认不勾选，重启UNO后也恢复关闭。
3. 点击STOP CAR，保存车速与地面设置，等待UNO confirmed，再点Start。无需开启陀螺仪导航，也无需输入地图。

## 关闭/开启的区别
关闭：地面循迹；右120/左360为定时估算，实际角度取决于电机速度。陀螺仪不会参与搜线、反向线路过滤、全黑区/交点稳向或PD角速度阻尼，因此不会触发搜线的FAULT10。位置估计和陀螺仪遥测继续显示，但不控制电机。
开启：停车后勾选Enable gyro-assisted search and heading hold，等待UNO确认。使用陀螺仪实测搜线角度、航向保持和方向筛选。没有新增全局地图/航点自动导航。

## 归零
停车后点击Zero heading and position (stopped)，等待UNO确认。以当前车头为0度，当前位置为X=Y=0，同时清零两套位置/航向估计。不会启动电机，也不会解除急停。
开启导航时自动归零；每次Start也自动归零。N213命令只允许UNO处于OFF，行驶中拒绝修改；GN遥测返回实际开关状态，ZR递增确认归零。
归零不等于陀螺仪零偏重新标定。零偏仍在开机时静止采样。左转YA应增加，右转减少；符号错误仍须调整Gyro Z sign，不能靠归零解决。

## 验证与限制
UNO真实AVR编译通过，Flash32064/32256，RAM1279/2048。主机测试覆盖实际N213命令处理、默认OFF、开启/关闭、归零、行驶拒绝、陀螺仪控制入口；既有交通/搜线/网页检查通过。ESP32仅主机桩接口语法检查，无本次目标编译或实机验证。
默认关闭红外遥控以保留Flash空间。Test5中已确认的红色像素阈值被任意红色信号覆盖的问题，本次导航开关修改未修复；不要把本版本当作该问题的修复版本。
